html · 示例

覆盖：标签/属性/注释/实体，以及内嵌 <style>、<script> 的嵌套着色。

基础用法

<!DOCTYPE html>
<html lang="en">
<head>
    <!-- 注释 -->
    <title>Demo</title>
</head>
<body>
    <h1 class="title">Hello, <span id="name">world</span>!</h1>
    <img src="./logo.png" alt="logo">
</body>
</html>

内嵌 style / script

<div class="box">Hello</div>

<style>
    /* 内嵌 CSS */
    .box {
        color: #ff0000;
        background: url("./bg.png");
        font-size: 13px;
    }
</style>

<script>
    // 内嵌 JS
    function greet (name) {
        const msg = "hello, " + name;
        return msg;
    }
    greet("world");
</script>
